## Условие задачи:

Вычисление факториала числа N (N!), Вариант 24

## 1.Алгоритм и блок схема:

### Алгоритм:

1.Начало
2.Объявление переменных N и fact = 1
3.Ввод пользователем числа N
4.Цикл от i = 1 до N с шагом 1: вычисление fact = fact * i
5.Вывод полученного факториала N!
6.Конец

## 2.Реализация программы

```c
#include <stdio.h>
#include <stdlib.h>
#include <locale.h>
#include <math.h>
#define _USE_MATH_DEFINES

int homework() {
	puts("HOMEWORK----------------------------------------------------------------------------------------------------------------");
	long int N = 0;
	long fact = 1;
	puts("Enter the N:");
	scanf_s("%d", &N);
	for (int i = 1; i <= N; i++) {
		fact = fact * i;
	}
	printf("%d! = %d ", N, fact);
}
```
